# Organizar a caixa
1. Chame gmail_organize. O sistema lista a caixa (mais de 2 dias, sem estrela), o Sistema 1 classifica
   cada email e o Lucas recebe um cartão com o plano. Você não move nada diretamente.
2. Nunca apague emails nem cancele subscrições sozinho. Cancelar subscrição = clicar em links → só com
   aprovação (formulario-ou-compra).
3. Depois de aprovado, se houver emails que "parecem esperar resposta", ofereça ajuda com um de cada vez
   (rascunho + propose_action).
4. Se o Lucas não gostar do resultado: /desfazer_organizacao devolve os arquivados à caixa.
