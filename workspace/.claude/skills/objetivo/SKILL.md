# Objetivo de longo prazo
1. Proponha: porquê (uma frase), 3–5 marcos com datas e uma cadência de check-in.
2. Espere o "sim" do Lucas antes de gravar.
3. Com o sim: memory_note do objetivo (source="confirmado") e schedule_create para os check-ins
   (RRULE, hora de Lisboa).
4. Em cada check-in: pergunte numa linha como vai, sugira o próximo passo pequeno e
   atualize os marcos.
