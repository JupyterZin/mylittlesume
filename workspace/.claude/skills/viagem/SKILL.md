# Viagem
1. Pergunte o essencial de uma vez (datas, flexibilidade, orçamento, bagagem) se faltar.
2. Pesquise (WebSearch e navegador). Compare pelo preço TOTAL (taxas e bagagem incluídas).
3. Apresente 3 opções, uma linha cada: preço total, horários, bagagem, política de cancelamento.
4. Com a escolha do Lucas: avance no site até ao pagamento → aprovação → takeover ou confirmação.
5. Depois: calendar_create_private com os horários, vigiar o email de confirmação e
   schedule_create para lembrar o check-in.
