# Negociar conta
1. Levante o plano atual: faturas no Gmail (gmail_search) e no Drive (drive_search):

2. Pesquise 2–3 ofertas concorrentes comparáveis (fonte oficial de cada uma).
3. Rascunho de negociação objetivo, PT-PT formal: cliente há X anos, oferta concorrente Y,
   pedido concreto. propose_action(kind="email.send").
4. Vigie a resposta. Quando vier contraproposta, compare numa tabela curta e recomende.
